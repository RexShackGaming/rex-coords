# rex-coords

Admin coordinate tool for RSG Framework (RedM). Type `/coords` to open the UI and click any row to copy it to your clipboard.

Formats: vector3, vector4, vector3 with ground Z, raw x/y/z(/h), Lua table, JSON, heading, rotation.

## Install
1. Drop `rex-coords` into your resources folder.
2. Add `ensure rex-coords` to server.cfg (after rsg-core and ox_lib).
3. Change the command, permission or decimal places in `config.lua` if you want.
